# CST Guest House team integration

The existing implementation comes from [Karma-Sonam/cst-guest-house](https://github.com/Karma-Sonam/cst-guest-house) at commit 440185e. The original repository records implementation authorship. This repository tracks each team member's integration and verification of their assigned batch.

Copy the contents of your assigned batch into the repository root on your team branch. Preserve the file paths. Open a pull request to main and describe what you integrated and verified. Merge the GitHub Actions batch last.
